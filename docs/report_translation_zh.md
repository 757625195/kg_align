## 1. 课题迭代与细化

### 1.1 当前研究主题

题目：通过联合 GNN-层次化 Transformer 和主动学习优化实现知识图谱语义对齐。

### 1.2 细化后的研究问题

- 我们提出一个融合图神经网络与层次化 Transformer 的异构数据语义对齐模型。
- 我们计划引入主动学习优化机制。
- 我们计划构建标准化实验协议，并选择具有代表性的跨语言与异构知识图谱数据集，例如 DBP15K、WK3l、DWY100K，开展实验。

### 1.3 最近的细化与反思

目前已经有许多将 GNN 与 Transformer 结合用于语义对齐的模型。然而，这些方法通常使用 GNN 学习结构表示、使用 Transformer 学习文本语义表示，随后在后期阶段将二者拼接或加权融合，再通过最近邻匹配或基于相似度的检索进行实体对齐，例如 RAGA、ActiveEA。这种方法存在两个关键局限：

1. 训练过程中没有强制耦合结构一致性和语义一致性，因此模型仍可能输出错误对齐，即“结构相似但语义上代表不同实体”或“语义相似但图结构完全不同”的情况。
2. 当两个知识图谱在语言、领域或数据模式上差异很大时，后融合模型往往只依赖某一种特征，即结构或语义，而忽略另一种特征。这会使模型在异构场景下出现明显偏置，缺乏对复杂分布和噪声的鲁棒性。

### 1.4 当前思路

1. 传统方法通常先独立提取结构特征和语义特征，再在输出层进行拼接，导致信息融合滞后。本文希望在训练过程中就将两类特征映射到统一嵌入空间中，受到 MCLEA 的启发。具体来说，图结构分支和语义文本分支都会映射到同一潜在空间，在其中联合建模并相互约束结构一致性，即多跳邻域位置是否对应，以及语义一致性，即文本描述是否等价。通过共享优化目标，实现结构-语义协同约束，使模型在学习过程中同时关注结构一致性与语义一致性。
2. 传统 Transformer 常被当作句子级编码器，把整个实体描述压缩成一个语义向量用于匹配。但在真实知识图谱中，实体描述通常很短，更像标签片段或跨语言的非对称摘要，语义信息分散在多个粒度上。为解决这个问题，本研究引入基于层次化 Transformer 的语义建模模块，在词或短语、句子或片段、实体三个层次上进行分层自注意力编码和渐进聚合。这种层次化多粒度语义建模受到 Hierarchical Attention Network 与 MG-BERT 等工作的启发，强调整合多粒度语义信息以提升实体匹配性能。
3. 在跨语言知识图谱实体对齐中，人工标注成本高，而且样本必须高质量。传统半监督方法常常受到错误伪标签传播的影响。为此，我借鉴 ActiveEA，将主动学习机制引入对齐框架：模型主动选择最不确定且最具代表性的候选对齐供人工标注，并将这些高价值标签实时反馈到训练中，形成一个低成本的闭环优化过程，以降低标注代价、提高对齐准确率，并缓解错误传播。

5. Multi-granularity Heterogeneous Graph Attention Networks for Extractive Document Summarization  
作者与来源：Zhao Y., Wang L. 等 / Neural Networks, 2022  
核心思想：基于多粒度语义单元，即句子、关键词、主题图的层次化注意力。

作者与来源：S. Zhang, J. Li, Y. Zhang, Y. Wang / ACL 2021

8. Entity Alignment with Reliable Path Reasoning and Relation-Aware Heterogeneous Graph Transformer

9. Multi-Modal Knowledge Graph Transformer Framework for Multi-Modal Entity Alignment, MoAlign  
作者与来源：Li Y., Zhao T., Zhang Z. 等 / EMNLP Findings 2023  
核心思想：使用多层 Transformer 编码器分层整合实体结构、文本和图像特征，用于多模态知识图谱之间的细粒度语义对齐。

## 3. 协同对齐框架设计

图 1：整体协同对齐框架。

本研究设计了一个融合轻量级 GNN、多尺度 Transformer 与主动学习闭环的协同对齐框架。该框架以两个异构知识图谱为输入，在统一嵌入空间中联合建模结构信息和语义信息，并通过增量式样本选择持续提升对齐质量。整体流程包含五个组成部分：全局图构建、结构编码、语义编码、跨模态增强，以及主动学习驱动的优化。

### 3.1 模型概览与信息流

设输入的两个知识图谱分别记为：

G1 = (V1, E1), G2 = (V2, E2)。

为了实现统一表示学习，将两图中的实体重新映射到共享的全局索引空间，得到：

G = (V, E), V = V1 ∪ V2, E = E1 ∪ E2。

对于每个实体 ei，模型学习结构表示 zstr_i、语义表示 zsem_i，以及最终联合表示 zjoint_i。框架的信息流可概括为：

ei → {zstr_i, zsem_i} → zjoint_i → s(ei, ej)，

其中 s(ei, ej) 表示来自不同图谱的两个实体之间的对齐分数。

### 3.2 统一对齐空间构建

该框架的核心思想是：将结构特征和语义特征映射到同一潜在空间并联合优化，而不是只在输出阶段进行融合。

#### 3.2.1 结构编码

结构分支采用轻量级多跳 GNN 对图拓扑进行编码。对于节点 i，记其邻居集合为 N(i)。第 l 层更新写为：

h_i^(l+1) = σ(W^(l) · AGG({h_i^(l)} ∪ {h_j^(l) | j ∈ N(i)}))。

经过多跳聚合后，结构表示为：

zstr_i = fgnn(ei, G)。

该分支用于在保持较低计算成本的同时捕获局部邻域模式和多跳关系依赖。

#### 3.2.2 语义编码

语义分支使用多尺度 Transformer 在不同粒度上建模实体文本。给定实体 ei 的语义序列，模型提取词元级、短语级和全局上下文表示：

ztok_i, zphr_i, zglb_i。

然后利用门控机制自适应组合这三个层次：

α_i = softmax(Wg[ztok_i; zphr_i; zglb_i])，

zsem_i = α_i^(1) ztok_i + α_i^(2) zphr_i + α_i^(3) zglb_i。

该设计使模型既能保留局部词汇语义，又能捕获长距离上下文信息。

#### 3.2.3 跨模态增强

在获得结构表示和语义表示之后，模型执行跨模态增强，而不是直接拼接。

首先，结构邻居通过注意力机制增强语义分支。对于语义表示 si 和邻居结构表示 {tk}，查询、键和值分别定义为：

qi = WQ si, kk = WK tk, vk = WV tk。

注意力权重计算为：

αik = softmax_k(q_i^T kk / sqrt(d))。

结构增强后的语义表示为：

Δsi = Σ_k αik vk，s_i^+ = si + Δsi。

其次，语义信息用于门控结构分支：

gik = σ(s_i^T Wm tk)，

t_i^+ = Ws ti + Σ_k gik tk。

最后，将增强后的语义向量与增强后的结构向量拼接，并投影到统一对齐空间：

zjoint_i = ffusion([s_i^+; t_i^+])。

这样，最终表示既保留关系结构又保留语义上下文，并允许两种模态在学习过程中相互约束。

### 3.3 对齐目标与训练策略

给定两个实体 ei ∈ G1 和 ej ∈ G2，对齐分数在共享空间中定义为：

s(ei, ej) = zjoint_i · zjoint_j / τ，

其中 τ 为温度参数。

训练时采用对比式对齐目标，使已对齐实体更接近、未对齐实体更远离：

Lalign = -Σ_i log exp(s(ei, e_i^+)) / Σ_j exp(s(ei, ej))。

为保证联合空间与各分支之间的一致性，引入结构一致性损失和语义一致性损失：

Lstr = Cons(zstr_i, zjoint_i)，Lsem = Cons(zsem_i, zjoint_i)。

总优化目标定义为：

L = Lalign + λ1 Lstr + λ2 Lsem + λ3 Lcm + λ4 Lneg，

其中 Lcm 表示跨模态一致性正则项，Lneg 表示负样本损失。

训练中采用分阶段策略。早期阶段强调结构自监督以稳定嵌入空间；后期逐步增强对齐监督、跨模态一致性和难负样本学习。训练同时使用随机负样本、批内难负样本和全局难负样本，以提升边界判别能力。

### 3.4 主动学习驱动的协同优化

为了降低标注成本并避免不可靠伪标签造成的错误传播，将主动学习机制嵌入训练循环。在若干训练轮之后，模型在统一对齐空间中评估未标注候选对，并选择信息量最大的样本进行标注。

对于候选对 x，其采集分数由不确定性和代表性共同决定：

Score(x) = λu U(x) + λr R(x)。

其中 U(x) 表示不确定性，R(x) 表示代表性。

不确定性项可由预测分布估计，例如结合熵和 margin：

U(x) = 1/2 Entropy(x) + 1/2 (1 - Margin(x))。

代表性项由联合空间、结构空间和语义空间共同估计：

R(x) = α Rjoint(x) + β Rstr(x) + γ Rsem(x)，且 α + β + γ = 1。

在按照 Score(x) 对候选对排序后，还会使用基于多样性的重排序步骤，避免从同一局部区域中选出冗余样本。最终标注得到的实体对会被重新加入训练集进行增量优化，形成如下闭环：

prediction → selection → annotation → update。

因此，本框架中的主动学习并不是外部后处理步骤，而是与统一对齐空间紧密耦合的。由于样本选择基于联合的结构-语义表示，被选中的候选更可能同时具有结构信息量和语义区分性，从而提升标签效率并降低噪声自举的风险。

### 3.5 小结

总之，所提出的协同对齐框架以统一对齐空间为中心，使用轻量级 GNN 编码结构依赖，使用多尺度 Transformer 建模层次化语义，使用跨模态增强模块融合并相互约束两个分支，再通过主动学习机制迭代提升监督质量。该设计使模型能够联合优化结构、语义和样本效率，为异构知识图谱实体对齐提供一种实用且可扩展的方案。

### 3.6 多尺度 Transformer 语义模块

本研究中的语义编码器实现为一个多尺度 Transformer 模块，其目标是在不同粒度上提取实体文本的语义信息，并将其投影到统一语义表示空间中。

给定实体 ei 的输入序列特征 Si ∈ R^(L×din)，其中 L 为序列长度、din 为输入特征维度，模块首先用线性投影将输入映射到隐藏空间：

Xi = Si Win + bin，Xi ∈ R^(L×d)。

在实现中，通过检查输入序列每一行是否为非零来构造有效 token mask：

mit = 1，当 Σ_k |Si,t,k| > 0；否则 mit = 0。

在此 mask 的基础上，模块中统一使用 masked mean pooling：

Pool(Hi) = Σ_t mit Hi,t / Σ_t mit。

1. 词元级表示  
词元级语义表示通过对投影后的输入序列直接执行 masked mean pooling 得到：
ztok_i = Pool(Xi)。

2. 短语级表示  
为了捕获局部短语模式，先将投影后的序列转成通道优先格式，再分别通过卷积核大小为 3 和 5 的两个一维卷积分支：
C_i^(3) = Conv1D_k=3(Xi)，C_i^(5) = Conv1D_k=5(Xi)。  
随后取两个分支输出的平均：
Ci = (C_i^(3) + C_i^(5)) / 2。  
再做 masked mean pooling，得到短语级表示：
zphr_i = Pool(Ci)。

3. 全局上下文表示  
为了建模长距离上下文依赖，将投影后的序列输入 Transformer 编码器：
Ti = TransformerEncoder(Xi)。  
然后做 masked mean pooling，得到全局上下文表示：
zglb_i = Pool(Ti)。

4. 带门控的多尺度融合  
在得到词元级、短语级和全局上下文表示后，模型将三者拼接：
hi = [ztok_i; zphr_i; zglb_i]。  
门控网络据此计算三个语义尺度的权重：
α_i = softmax(MLPgate(hi))，
其中 α_i = [α_i^(1), α_i^(2), α_i^(3)]。  
不同于直接加权求和，该实现先用对应门值缩放各尺度表示，再重新拼接：
fi = [α_i^(1) ztok_i; α_i^(2) zphr_i; α_i^(3) zglb_i]。  
拼接后的多尺度向量再送入输出投影网络：
zsem_i_tilde = MLPout(fi)。  
最后对语义表示做归一化：
zsem_i = zsem_i_tilde / ||zsem_i_tilde||2。

因此，实现中的完整语义编码过程可以概括为：

Si → Xi → {ztok_i, zphr_i, zglb_i} → α_i → fi → zsem_i。

这一设计严格遵循代码实现：模型先提取词元级、短语级和全局上下文特征，再用门控机制估计各尺度的贡献，把加权结果拼接后投影到统一语义嵌入中。

### 3.7 基于轻量级 GNN 的多跳邻居聚合与结构对齐机制

为了有效利用跨知识图谱实体对齐中的结构信息，本研究设计了一个基于轻量级 GNN 的多跳邻居聚合与结构对齐机制。该模块的目标是在控制计算开销的前提下，对实体的局部邻域结构和高阶拓扑上下文进行编码。

在当前实现中，该模块由以下部分构成：轻量级结构编码、固定预算邻居采样、显式多跳结构特征提取、结构一致性正则，以及显式的 2-hop/3-hop 拓扑匹配目标。这些组件共同为后续的结构-语义协同对齐提供可靠的结构嵌入。

#### 3.7.1 轻量级 GNN 的设计原则

跨图谱实体对齐通常涉及大规模图，包含大量实体和边。因此，基于稠密全图传播的传统图编码器在实践中往往难以扩展。为此，当前结构编码器遵循三条设计原则。

第一，计算稀疏化。编码器建立在稀疏图传播和固定预算邻居采样之上，而不是稠密邻域扩张或面向所有实体的全局注意力。设输入图为 G = (V, E)，其中 V 为实体集合，E 为边集合。每个实体 ei ∈ V 都有一个可训练的初始嵌入 h_i^(0) ∈ R^din。结构编码器随后采用堆叠式 GraphSAGE 传播：

h_i^(l+1) = SAGEConv(h_i^(l), {h_j^(l) | j ∈ N(i)})。

第二，参数压缩。当前实现额外引入了两种可选机制来进一步缩小模型规模：跨层参数共享和深度可分离图卷积。前者在兼容的层之间复用卷积参数；后者将图传播分解为轻量级邻域聚合阶段和通道级投影阶段。

第三，表示稳定性。为了防止轻量化设计削弱结构表达能力，在输入嵌入到最终结构表示之间加入残差连接：

zstr_i_tilde = h_i^(L) + Wr h_i^(0)，

最终结构嵌入为：

zstr_i = zstr_i_tilde / ||zstr_i_tilde||2。

因此，当前代码中的轻量级 GNN 并不只是浅层图编码器，而是一个稀疏、保残差、并且可选地进行参数压缩的结构编码器，目的是在效率与表达力之间取得平衡。

#### 3.7.2 多跳邻居聚合策略

实体的结构语义往往不仅依赖直接邻居，还依赖更高阶的拓扑上下文。例如，一个组织的语义可能需要通过“组织 → 地点 → 国家”这类路径才能更好地刻画。因此，仅依赖一跳邻居通常是不够的。

在当前实现中，多跳结构建模通过两种互补机制实现。

第一，多跳信息由堆叠的 GraphSAGE 层隐式捕获。因为每一层都会聚合一次邻居信息，所以最终嵌入自然包含高阶结构上下文。经过 L 层后，节点表示可以被看作融合了最多 L 跳的信息。

第二，实现中还会在结构空间里显式构造高阶 hop 摘要。以学习到的结构嵌入矩阵 Zstr = [zstr_1, zstr_2, ..., zstr_|V|] 为起点，模型反复执行轻量级邻居均值聚合，得到分 hop 的结构摘要：

Z(1) = Agg(Zstr, E)，  
Z(2) = Agg(Z(1), E)，  
Z(3) = Agg(Z(2), E)。

其中 Agg(·) 表示代码中实现的邻域均值聚合算子。这样，模型就能为每个实体显式得到 2-hop 和 3-hop 的结构摘要。

此外，在训练和推理期间，模型还会为每个实体采样固定数量的邻居：

N_K(i) = {ni1, ni2, ..., niK}，

其中 K 是预设的邻居预算。对应的二值 mask 定义为：

mik = 1，当第 k 个采样邻居有效；否则 mik = 0。

这种设计保证了局部结构上下文被保留下来，同时避免邻域无控制扩张。

因此，当前的多跳邻居聚合策略可概括为：显式一跳邻居采样、通过堆叠稀疏 GNN 层实现的隐式多跳传播，以及在已学习结构空间中显式构造 2-hop/3-hop 结构摘要。

#### 3.7.3 结构一致性约束与跨知识图谱拓扑对齐

在实体对齐中，结构相似性是识别跨图谱等价实体的重要线索之一。为了在最终对齐空间中保留结构信号，当前实现采用了两个面向结构的机制。

第一个是结构一致性约束。设 zjoint_i 表示实体 ei 在统一对齐空间中的最终联合嵌入。结构分支通过一致性损失被约束为接近联合分支：

Lstr = Lcons(zstr_i, zjoint_i)。

在当前代码中，一致性函数结合了余弦项和 smooth-L1 项：

Lcons(x, y) = 1/2 [1 - x^T y / (||x||2 ||y||2)] + 1/2 SmoothL1(x, y)。

这种形式同时保留了结构空间与联合空间之间的方向相似性和几何接近性。

第二个是显式高阶拓扑匹配目标。对于跨两个知识图谱的一个正对齐实体对，模型不仅对齐最终联合嵌入，也直接对齐它们的高阶结构摘要。设 zhop_i,2 和 zhop_i,3 分别表示实体 ei 的 2-hop 和 3-hop 结构摘要，则拓扑匹配损失定义为：

Ltopo = 1/2 (Lba(zhop_i,2, zhop_j,2) + Lba(zhop_i,3, zhop_j,3))。

其中 Lba(·) 是当前实现中使用的分支对齐损失。由于这一损失同时结合对比式目标和光滑对齐目标，它也会显式鼓励对齐实体在高阶结构空间中彼此接近。

需要指出的是，当前实现对齐的是显式的高阶结构表示，而不是执行子图级图匹配或图编辑距离计算。因此，更准确的说法应当是：显式的 2-hop/3-hop 拓扑表示对齐。

#### 3.7.4 复杂度与可扩展性讨论

从当前实现的角度看，轻量级 GNN 模块的计算效率主要得益于三个机制：稀疏图传播、固定预算邻居采样和参数压缩。

在传统全邻居传播中，层级复杂度与全部边甚至稠密的成对交互紧密相关。相比之下，当前设计只在观测到的边上执行稀疏 GraphSAGE 传播，而局部交互部分还通过固定大小的邻居采样加以控制。令 |E| 表示图边数，K 表示采样邻居大小，那么结构传播成本大致与稀疏图规模成正比，而局部融合相关成本大致对 K 线性增长。

当启用可选参数共享时，多层会复用兼容的卷积模块，从而减少可训练参数量。当启用深度可分离图卷积时，图层被分解为轻量级聚合阶段和投影阶段，进一步降低参数开销。

此外，当前显式多跳拓扑建模并不会枚举所有 2-hop 或 3-hop 子图，而是在学习到的结构空间中通过重复聚合得到高阶结构摘要。这避免了显式邻域爆炸带来的巨大计算成本，同时仍保留有用的高阶拓扑信息。

因此，与更重的结构编码器相比，当前实现已经在机制层面提供了可扩展性的实用基础。但也要强调，仓库目前仍不包含专门的复杂度基准测试脚本、工业级分布式训练流水线或系统化的大规模部署实验。因此，当前实现应被理解为一种在机制层面轻量且可扩展的结构设计，而不是一个已经充分验证的工业系统。

### 3.8 跨模态特征增强与主动学习驱动优化

在获得结构表示和多尺度语义表示之后，模型进一步引入跨模态增强机制，以提升统一实体嵌入的质量。同时，在训练循环中加入主动学习策略，以便在有限监督下选择更有信息量的候选实体对。

#### 3.8.1 跨模态结构-语义增强

设实体 ei 的语义表示为 si ∈ R^d，自身结构表示为 tself_i ∈ R^d，采样得到的邻居结构表示为 Tnei_i = {ti,1, ti,2, ..., ti,K}，其中 ti,k ∈ R^d。邻居 mask mik ∈ {0, 1} 用于指示第 k 个采样邻居是否有效。

1. 从结构到语义的注意力  
语义表示首先作为 query，对邻居结构特征进行注意力聚合：
qi = Wq si，ki,k = Wk ti,k，vi,k = Wv ti,k。  
第 k 个邻居的注意力分数为：
ei,k = q_i^T ki,k / sqrt(d)。  
经过 mask 和归一化后，注意力权重为：
αi,k = mik exp(ei,k) / Σ_j mij exp(ei,j)。  
聚合后的结构信号为：
Δsi = Σ_k αi,k vi,k。  
增强后的语义表示为：
s_i^+ = si + Δsi。

2. 从语义到结构的门控  
语义表示同样用于门控邻居结构特征：
gi,k = s_i^T Wg ti,k。  
其中 Wg ∈ R^(d×d) 为可学习投影矩阵。经过 sigmoid 激活和 masked normalization 后，门控权重为：
βi,k = mik σ(gi,k) / Σ_j mij σ(gi,j)。  
门控后的邻居聚合为：
tnei_i_hat = Σ_k βi,k ti,k。  
再将其与变换后的自身结构结合，得到增强后的结构表示：
t_i^+ = Ws tself_i + tnei_i_hat。

3. 联合融合  
将增强后的语义与结构表示拼接并投影到联合空间：
ui = [s_i^+; t_i^+]，  
zjoint_i_tilde = MLPfus(ui)。  
经过 layer normalization 和 L2 normalization 后，得到最终联合表示：
zjoint_i = LayerNorm(zjoint_i_tilde) / ||LayerNorm(zjoint_i_tilde)||2。  
同时，增强后的分支表示也会归一化：
zsem_i^+ = s_i^+ / ||s_i^+||2，zstr_i^+ = t_i^+ / ||t_i^+||2。

因此，跨模态增强过程可概括为：

(si, tself_i, Tnei_i) → (s_i^+, t_i^+) → zjoint_i。

#### 3.8.2 联合对齐目标

给定一批已对齐实体对，设左侧和右侧的联合嵌入分别为 {z_i^L}_i=1^B 和 {z_i^R}_i=1^B。主对齐目标是双向 InfoNCE 损失：

Lalign = 1/2 (L_L→R + L_R→L)。

为了进一步稳定联合空间，实现中还引入分支级对齐与一致性约束。设 z_i,str^{L+}、z_i,str^{R+} 表示增强后的结构嵌入，z_i,sem^{L+}、z_i,sem^{R+} 表示增强后的语义嵌入，则分支对齐损失定义为：

Lbranch = 1/2 (Lba(z_str^{L+}, z_str^{R+}) + Lba(z_sem^{L+}, z_sem^{R+}))。

跨模态一致性损失为：

Lcross = 1/2 (Lcons(z_str^{L+}, z_sem^{L+}) + Lcons(z_str^{R+}, z_sem^{R+}))。

联合分支一致性损失为：

Ljoint_branch = 1/4 (Lcons(zjoint^L, zstr^{L+}) + Lcons(zjoint^L, zsem^{L+}) + Lcons(zjoint^R, zstr^{R+}) + Lcons(zjoint^R, zsem^{R+}))。

因此，总训练损失可写为：

L = Lalign + λb Lbranch + λc Lcross + λj Ljoint_branch + λn Lneg + λt Ltopo。

#### 3.8.3 主动学习驱动的样本选择

为了在有限监督下提高样本效率，模型会在训练过程中周期性执行主动学习。设左右两侧候选实体集合分别编码为 ZL ∈ R^(NL×d)、ZR ∈ R^(NR×d)，它们的相似度矩阵为：

M = ZL ZR^T。

对于左侧第 i 个实体，匹配概率分布为：

pij = exp(Mij / τ) / Σ_k exp(Mik / τ)。

熵定义为：

Hi = -Σ_j pij log pij。

设第 i 行中最大和第二大的相似度分别为 Mi(1) 和 Mi(2)，则 margin 为：

Δi = Mi(1) - Mi(2)。

于是，不确定性分数定义为：

Ui = 1/2 Hi + 1/2 (1 - Δi)。

为衡量代表性，实现中会在联合空间、增强结构空间和增强语义空间中分别计算候选样本的中心性。对任意嵌入集合 {xi}，其中心为：

c = 1/N Σ_i xi，

样本 i 的中心性分数为：

Ri(x) = cos(xi, c)。

因此，多视图代表性分数为：

Ri = αj Ri(zjoint) + αs Ri(zstr+) + αm Ri(zsem+)。

最终主动学习分数定义为：

Fi = βu Ui + βr Ri。

候选实体对会按照 Fi 排序，再按置信度、margin、不确定性范围以及可选的双向一致性进行过滤。最后再通过多样性重排序减少选中候选之间的冗余。

#### 3.8.4 增量式样本反馈

被选中的候选实体对并不会被直接当作伪标签。相反，在当前实现中，代码会基于 ground-truth 对齐对进行 oracle 风格模拟，用来判断候选是否真正为正样本。若某个候选对被确认为正样本，它就会被追加到训练对集合中，并在后续 epoch 中参与训练。由此形成如下增量式优化闭环：

training → candidate scoring → sample selection → positive pair feedback → continued training。

这种设计通过跨模态增强提升联合嵌入质量，再通过主动学习驱动的样本反馈进一步优化对齐边界。

## 4. 为什么要使用主动学习？

1. 跨知识图谱实体对齐的内在挑战  
基于 2024 年一篇关于图嵌入实体对齐综述的观点：

a. 种子样本稀缺  
- 实体对齐模型高度依赖人工标注的种子对齐对。但在真实跨图谱场景中，真正对齐的实体极其稀少，标注代价高，正样本数远小于负样本数。因此，大多数模型都会面临优化困难、泛化不足以及在种子区域过拟合的问题。  
- 种子分布存在偏差。已有种子通常覆盖“容易”的实体，如高频实体、结构显著实体，却很少覆盖“困难”区域，例如语义差异大或局部结构稀疏的区域。这会造成对困难案例监督不足，并导致图上不同区域的性能极不均衡。

b. 伪标签风险与错误传播  
- 早期预测不稳定。在训练初期，模型预测通常不可靠，导致伪标签错误率很高。  
- 错误会在自举过程中被放大。一旦错误伪标签被纳入训练，就会污染嵌入空间，造成全局漂移。BootEA、IMUSE、MRAEA 等基于 bootstrapping 的方法都面临这一风险。

2. 主动学习的动机  
为了构建一个轻量、可部署、可扩展的实体对齐模型，必须引入主动学习模块。在数据规模极大但人工标注预算有限的场景下，主动学习能够提升信息量样本的利用效率，并确保模型即使在大规模知识图谱上也能保持稳定训练效率。

3. 主动学习在本模型中的优势  
在构建统一对齐空间后，我们的模型融合了基于多尺度 Transformer 的语义编码和基于 GNN 的结构编码。这使得样本选择同时具有语义信号与结构信号，从而使主动学习模块能够识别那些先天高质量的候选对，即在结构上关键、在语义上可区分的候选。这一点相比以往引入主动学习的实体对齐模型具有明显优势。

## 9. 评价指标

为客观评估所提模型在知识图谱实体对齐任务上的性能，本文采用三种广泛使用的排序型指标：Hits@1、Hits@10 和 MRR，即平均倒数排名。

设 ei 为源知识图谱中的一个实体，e*_i 为其在目标图谱中的真实对齐实体。对于每个源实体，模型根据相似度分数对目标图中的所有候选实体做降序排序。设 rank_i 为真实对齐实体 e*_i 的排名位置，N 为测试样本总数，则：

Hits@k = 1/N Σ_i I(rank_i ≤ k)

MRR = 1/N Σ_i 1/rank_i

其中 I(·) 为指示函数，条件满足时取 1，否则取 0。

在这些指标中，Hits@1 衡量真实对齐实体排在首位的比例，反映模型的精确匹配能力；Hits@10 衡量真实对齐实体是否出现在前 10 个候选中，反映高置信候选集合上的召回能力；MRR 则通过对真实对齐实体倒数排名取平均来衡量整体排序质量。指标越高，说明模型在统一表示空间中的区分能力越强，实体对齐性能越好。

## 10. 实验环境与实现细节

为了验证所提模型在跨语言知识图谱实体对齐任务上的有效性，所有实验均在统一实验设置下进行。实验运行在 Apple Mac mini 上，硬件为 Apple M4 芯片、10 核 CPU、16GB 内存，操作系统为 macOS 26.3.1。模型使用 Python 3.9.6 实现，深度学习框架为 PyTorch 2.8.0，图数据处理和图神经网络操作使用 PyTorch Geometric 2.6.1。

在训练流程上，模型采用两阶段优化策略。第一阶段是 Warmup，用于稳定结构表示空间，提升联合优化初期的训练鲁棒性。第二阶段是 Joint Training，在统一嵌入空间内同时优化结构表示、语义表示和融合表示。整体训练流程由 `train.py` 管理。

在优化器和超参数设置方面，使用 AdamW，初始学习率为 1×10^-3，batch size 为 128，weight decay 为 1×10^-5，dropout 为 0.1。Warmup 训练 5 个 epoch，Joint Training 训练 15 个 epoch。为缓解训练后期性能退化，联合训练中使用 early stopping，并依据评测指标选择最优模型参数。在当前实现中，early stopping 的 patience 设置为 4。

从模型架构角度看，结构分支使用轻量级 GNN 编码器建模实体图结构上下文，语义分支使用层次化 Transformer 编码器进行语义表示学习。结构与语义特征随后通过跨模态融合模块整合，并在统一嵌入空间中进行实体匹配。训练时，分支对齐损失、跨模态一致性损失和联合-分支一致性损失并不会在一开始同时启用，而是分阶段逐步加入，以降低过强协同约束导致的不稳定。

在负样本采样方面，当前实现结合了随机负样本、批内难负样本和基于 memory bank 或 queue 的全局难负样本，以提高模型对困难样本的判别能力。主动学习部分是在模拟主动学习场景下实现的：先根据不确定性、代表性和多样性生成候选对，再利用置信度、margin 和不确定性阈值进行过滤，最后使用真实对齐对模拟人工反馈，将高价值正样本增量加入训练集。

还需要指出的是，当前实验并没有对原始实体文本做 tokenization，也没有截断到固定最大长度如 128。相反，模型直接使用数据集提供的固定长度语义特征序列。根据当前实验设置，输入语义特征张量形状为 `(38960, 14, 300)`，即共有 38960 个实体，每个实体用长度为 14、维度为 300 的语义序列表示。因此，本工作中的层次化语义建模是建立在预处理后的固定长度语义表示之上，而不是直接作用于原始 token 序列。

## 11. 主要实验结果

本节报告所提出完整模型在 DBP15K `zh_en` 数据集上的主要实验结果。完整框架在统一嵌入空间中集成了轻量级结构编码器、层次化语义编码器、跨模态增强模块以及主动学习策略。

根据当前实验结果，完整模型在跨语言实体对齐任务上取得了稳定且有竞争力的表现。在本研究得到的最佳配置下，模型在 DBP15K `zh_en` 上的最佳 Hits@1 为 0.6381，同时 Hits@10 和 MRR 也保持较强表现。这些结果表明，所提出的框架能够有效结合结构上下文与语义信息，实现跨图谱实体匹配。

从训练日志来看，完整模型在联合训练阶段呈现出较稳定的提升趋势。与更早版本的实现相比，当前训练配置避免了后期 epoch 中曾出现的严重性能崩塌。这一改进主要归因于协同损失的分阶段激活、增强的难负样本采样策略，以及训练过程中的 early stopping。

此外，实验结果表明，结构与语义的联合建模对提升对齐质量具有关键作用。结构分支提供感知拓扑的上下文信号，语义分支提供跨语言语义线索。它们通过跨模态增强模块发生交互，进一步提升最终联合嵌入空间的质量，从而提高对齐精度。

完整模型还受益于模拟主动学习设置。与不使用主动学习的配置相比，完整模型在 Hits@1 上取得了小幅但稳定的提升，说明在有限监督条件下，主动学习策略能够改善样本效率。尽管当前实现采用的是模拟标注而非真实 human-in-the-loop 标注，但结果仍然展示了样本选择对于实体对齐任务的实际价值。

## 12. 导师反馈与讨论结果

1. “没有定义 knowledge graph 指的是什么。是 RDF 三元组集合还是别的东西？”  
回应：本研究中的知识图谱在形式上以 RDF 三元组为基础，语义上与 RDF schema 一致，但在实现上被转换为适配 GNN 的图结构格式。  
文中补充的定义是：知识图谱通常被定义为由实体，即节点、关系，即边、属性，即字面值共同组成的多关系图。  
例如 RDF 三元组：  
- (Paris, isCapitalOf, France)  
- (France, population, 66M)  
- (France, locatedIn, Europe)  
可表示为图结构：  
Paris --isCapitalOf--> France --locatedIn--> Europe  
同时 France 还带有属性 population = 66M。  
也就是说，Paris、France、Europe 是实体节点；isCapitalOf 和 locatedIn 是关系边；population=66M 是属性值。这样，RDF 三元组就自然转成适合 GNN 处理的图结构表示。

2. “已经有很多结合 GNN 和 Transformer 的语义对齐模型，引用呢？”  
回应：已补充近期将 GNN 与 Transformer 结合用于语义对齐、尤其是实体对齐场景的工作，如 IJCAI 2022 的 RPR-RHGT 和 EMNLP Findings 2023 的 MoAlign。

3. “模型可能会输出‘结构相似但语义不同’或‘语义相似但结构完全不同’的错误对齐，需要示例。”  
回应：结构相似但语义不同的例子可以是 `cat` 和 `dog`。在宠物相关知识图谱中，它们都可能连向 `owner`、`breed`、`diet`、`lifespan` 等类似关系，因此局部结构几乎同构，但语义上显然不是同一实体。另一个例子是 `movie` 和 `film`。虽然经常被视为近义词，但二者在具体语境中的关系邻域可能不同，导致主要依赖结构相似性的 GNN 模型产生错误对齐。

4. “‘post-fusion models’ 指什么？”  
回应：所谓“后融合模型”是指 GNN 与 Transformer 分别独立训练，各自产生的特征只在模型最后阶段通过简单拼接或加权平均进行融合。这种设计在训练过程中缺乏结构-语义联合约束。

5. “‘在训练过程中把两种特征映射到统一嵌入空间中（MCLEA）’ 这个想法需要描述清楚，还要和拼接做比较。”  
回应：目前还在考虑这一方案，尚未完成验证。受 MCLEA 启发，计划先把 GNN 和 Transformer 的输出映射到共享嵌入空间，再通过模态间对齐损失拉近同一实体在不同模态中的表示，通过模态内对比损失区分正确匹配和错误匹配。本周内会给出更详细方案。

10. “为什么你认为仅仅拼接再接两层 MLP 就能得到想要的结果？”  
回应：真正关键的不是最后的 MLP 和拼接本身，而是在拼接之前先增强原始结构向量和语义向量。  
a. 通过互注意力计算结构特征对语义特征的影响权重，把结构信息聚合到语义向量中，得到增强语义向量。  
b. 通过语义门控调节结构分支权重，使结构向量融入语义信息，得到增强结构向量。  
之后先完成两条分支的增强，再进行融合与拼接，从而产生整体增强效果。
