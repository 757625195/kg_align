# 关系感知结构—语义早期交互的跨语言知识图谱实体对齐方法

Original Research

作者：林心怡（LIN XINYI）

## 摘要

跨语言知识图谱实体对齐需要同时处理关系结构不一致、实体文本碎片化和监督样本有限等问题。针对结构与语义在末端融合时难以充分交互的局限，本文提出一种关系感知结构—语义早期交互方法。该方法利用关系嵌入和共享投影构造轻量级图消息，通过节点级层选择融合不同传播深度；同时从 token、phrase 和 global 三个尺度编码实体语义，并在结构上下文形成之前以语义表示引导邻居注意力和门控聚合。本文在 DBP15K ZH–EN 与 OpenEA EN–FR 15K V2 上采用三个随机种子进行评估。主模型的排名第一命中率（Hits@1）分别为 0.6768±0.0005 和 0.4885±0.0112；晚期拼接基线分别为 0.5782±0.0024 和 0.2153±0.0368。移除多尺度语义编码器后，OpenEA 的 Hits@1 降至 0.3138。结果表明，在给定数据划分和训练协议下，关系感知结构编码、跨层选择和语义引导的早期交互具有稳定贡献；然而，global 语义视图、结构预热、复合负样本目标和低预算主动学习尚未获得跨数据集的一致支持。本文据此界定已获支持的机制、负面结果及适用边界，并为参数匹配的融合比较和更严格的主动学习评价提供依据。

关键词：知识图谱实体对齐；跨语言知识图谱；关系感知图神经网络；多尺度语义编码；结构—语义融合

## 1 引言

### 1.1 研究背景与问题缺口

知识图谱以三元组 $(h,r,t)$ 表示实体之间的事实关系。不同机构、语言和业务系统通常独立构建知识图谱，因此同一现实对象可能具有不同标识符、名称、属性和值域。例如，同一人物在中文 DBpedia 和英文 DBpedia 中可能使用不同语言的实体名称，同时两侧图谱记录的邻居数量、关系方向和属性完整度也不相同。实体对齐的任务是在两个实体集合 $E_1$ 和 $E_2$ 之间寻找等价关系，从而为图谱合并、跨语言问答和知识补全建立桥梁。

现有方法大致形成三条技术路线。MTransE 和 JAPE 将不同图谱嵌入到可映射或共享的向量空间中[1–2]；BootEA 在训练过程中迭代筛选高置信候选，并将其作为伪标签扩充监督集合[3]；RDGCN 和 RREA 则显式利用关系与邻域拓扑增强结构表示[4–5]。这些研究奠定了跨语言实体对齐的主要方法基础，但结构证据与文本证据如何在统一模型中有效交互，仍存在三项具体困难。

第一，结构相似不等于实体等价。两个实体可能都连接到“人物、地点、组织”等相似类型的邻居，但连接关系分别是“出生地”和“工作地点”，或者关系方向相反。若图编码器把边退化为无类型邻接，它们可能得到相似表示。第二，语义证据往往是碎片化的。实体输入不是完整文章，而是由名称、关系词和属性值拼成的短序列；“Washington”只有结合局部词组和更广上下文才能区分人物、州或城市。第三，监督信号有限。种子对齐只能覆盖实体集合的一部分，而低质量伪标签一旦在早期被加入训练，会改变表示空间并扩大错误影响。

### 1.2 研究目标与论文贡献

本研究的核心目标是检验结构与语义的交互位置是否影响跨语言实体检索。由此提出三个可检验假设：关系类型与不同传播深度能够提高结构表示的区分性；多尺度编码能够改善由名称和属性片段构成的实体文本表示；在结构上下文形成之前引入语义条件，比两个分支独立编码后的末端融合更有效。实验同时考察这些效应在不同数据集和随机种子下的稳定性，并将主动学习作为探索性扩展单独评价。

### 1.3 主要贡献

本研究的创新不在于重新提出图神经网络、Transformer 或主动学习基本理论。GraphSAGE 邻域聚合[6]、R-GCN 关系建模[7]、Transformer 自注意力[8]、InfoNCE 对比目标[9]、结构感知主动学习[10]和可扩展标签传播[11]均建立在已有研究基础上。本文的主要贡献如下：

1. 提出一种关系感知轻量结构编码器，以关系嵌入和共享投影构造邻域消息，并通过逐维门控与节点级层选择联合建模实体自身状态、关系类型及 0 到 $L$ 跳结构信息。
2. 构建三尺度语义编码与早期交互模块，使语义表示在结构上下文形成之前参与邻居打分和门控聚合，并设置晚期拼接与简单平均两个控制组检验交互位置。
3. 在两个跨语言数据集上开展三随机种子主实验、核心消融和补充分析，区分稳定证据、探索性观察与不支持原假设的结果，并报告低预算主动学习的适用边界。

## 2 相关工作

### 2.1 基于平移和共享空间的方法

MTransE 分别学习不同语言图谱的实体与关系嵌入，再通过轴校准、平移向量或线性变换建立跨语言映射[1]。JAPE 在共享结构空间的基础上进一步利用属性相关性，并发布了后来被广泛使用的 DBP15K 数据集[2]。这类方法结构清晰，但平移假设难以表达复杂多关系结构，而且映射矩阵可能破坏两侧嵌入空间的相对几何关系。

BootEA 通过 bootstrapping 迭代选择可能正确的实体对并加入训练，同时设计对齐编辑机制以减轻错误积累[3]。它说明未标注数据可以提高实体对齐效果，但也暴露了伪标签方法的核心风险：若早期高分错误被当作真值，后续训练会不断强化错误边界。因此，本文的主动学习模块不会直接将模型预测作为训练标签，而是将候选实体对交给标注者确认；在模拟实验中，标注者由数据集真值构成的 oracle 代替。确认正确的匹配加入训练集，错误匹配则作为负反馈保存。

### 2.2 基于图神经网络的关系建模

GraphSAGE 提出了采样并聚合局部邻域的归纳式图表示学习框架[6]。R-GCN 则针对多关系图为不同关系设计消息变换[7]。然而，当关系类型较多时，为每种关系配置独立大矩阵会显著增加参数量，并使低频关系难以获得充分训练。因此，本文使用关系嵌入和共享线性投影构造轻量级关系感知消息，在控制模型复杂度的同时保留关系类型信息。

在实体对齐领域，RDGCN 构造实体图与关系对偶图之间的注意力交互，并证明关系信息有助于区分具有相似邻居但关系语义不同的实体[4]。RREA 从几何保持角度提出关系反射变换，并指出实体对齐中的变换需要兼顾关系区分和空间等距性[5]。与上述方法不同，本文采用源实体表示、关系嵌入和邻居表示的门控消息更新方式，并融合不同图神经网络层的输出，以综合利用不同传播深度的结构信息。

RPR-RHGT 进一步使用可靠路径推理和关系感知异构图 Transformer 联合建模关系与多步路径[12]。与之不同，本文不生成、筛选或编码显式关系路径；多跳信息仅来自三层图神经网络的消息传播和跨层选择。因此，本文研究的是多跳邻域聚合，而非路径级推理。

### 2.3 语义建模与联合表示

Transformer 通过多头自注意力建模序列中任意位置之间的依赖[8]。HAN 则表明，词语、句子等不同粒度的信息对整体表示具有不同贡献[13]。受此启发，本文分别从单词、局部短语和完整序列三个尺度提取实体文本特征：token 视图保留细粒度信息，phrase 视图提取局部语义模式，global 视图使用两层 Transformer 建模长距离依赖。本文仅借鉴 HAN 的多粒度思想，并未采用其双层 GRU 结构。该设计控制了计算开销，但跨语言效果仍受输入词向量、翻译结果和属性预处理质量影响。

已有文本增强实体对齐方法表明，名称和描述可以显著改善跨语言匹配；RREA 的文本版本也将文本方法与纯结构方法分开比较[5]。MCLEA 分别编码多种模态，并用模态内对比与模态间对齐目标共同构造实体表示[14]；Li 等人的多模态图谱 Transformer 工作则指出，直接拼接或注意力组合异质信息可能形成未对齐的信息空间[15]。这些工作处理的输入还包含图像等模态，不能直接等同于本文的结构—文本设置，但它们共同支持一个需要验证的假设：交互位置和对齐约束比“是否进行了融合”本身更重要。本文因此把语义划分为 token、phrase 和 global 三种尺度，并让语义向量在结构邻居聚合前参与打分；第 5 节进一步用晚期拼接基线直接检验这一点。

### 2.4 主动学习与可扩展对齐

ActiveEA 将实体之间的图依赖纳入采样价值，提出结构感知不确定性策略，并讨论无对应实体会浪费标注预算的问题[10]。LightEA 则从可扩展性角度使用三视图标签传播和稀疏 Sinkhorn 操作，说明复杂神经模型并非唯一有效路线[11]。本文主动学习模块借鉴 ActiveEA 的结构感知不确定性，但当前数据集仍采用一对一、闭世界候选假设，尚未实现无对应实体（bachelor entity）识别。本文也没有证明相对于 LightEA 等方法的计算优势，因此“轻量”只表示当前结构消息形式、固定邻居预算和小型语义编码器较为克制，不等同于已完成的大规模效率基准。

综上，现有研究分别证明了关系结构、文本语义和主动查询的价值，但仍缺少在统一实验协议下对“语义何时进入结构计算”的直接控制。本文据此将早期语义引导聚合与晚期拼接、简单平均置于相同数据划分和训练流程中比较，并通过可分离消融考察关系消息、层选择和多尺度语义的作用。

## 3 材料与方法

### 3.1 实体对齐任务

给定两个知识图谱

$$G_1=(E_1,R_1,T_1),\qquad G_2=(E_2,R_2,T_2),$$

其中 $E$、$R$ 和 $T$ 分别表示实体集合、关系集合和三元组集合。已知少量种子对齐

$$A_{seed}=\{(e_i,e_j)\mid e_i\in E_1,e_j\in E_2,e_i\equiv e_j\},$$

目标是学习评分函数 $s(e_i,e_j)$，使真实对应实体在候选集合中获得更高排名。当前评估采用一对一闭世界设定：测试集中每个左侧实体在右侧候选集中存在一个真实对应实体。

### 3.2 研究设定与关键定义

种子对齐（seed alignment）是训练前已知的正确实体对，它们提供跨图监督锚点。难负样本（hard negative）是当前模型评分较高但不是真实匹配的候选，例如真实实体排在第二名时位于第一名的错误实体。它比随机负样本更接近当前对齐边界，因此对训练判别能力更有价值。

早期错误（early error）指模型尚未形成稳定表示时产生的高置信错误。如果将其作为伪标签加入训练，后续表示会围绕错误监督重新组织。朴素伪标签（naive pseudo-labeling）就是直接根据模型分数接受预测而不经过外部确认、互惠检查或可靠性过滤。本文的主动学习模块通过 oracle 或人工标注确认候选，并允许返回 no_match 负反馈。

对齐边界（alignment boundary）指真实候选与最强错误候选分数接近的区域。若第一名和第二名的分差很小，模型对实体归属不确定。交互就绪上下文（interaction-ready context）在本文中特指：全图结构编码完成后，为每个待匹配实体提取固定数量 $K$ 的邻居表示与有效掩码，使其能够直接进入语义引导的注意力和门控计算。

### 3.3 符号约定

| 符号 | 含义 |
|---|---|
| $h_i^{(l)}$ | 实体 $i$ 在第 $l$ 层的结构状态 |
| $e_r$ | 关系 $r$ 的可学习嵌入 |
| $z_i^{tok},z_i^{phr},z_i^{glo}$ | token、phrase、global 三个语义视图 |
| $z_i^{sem}$ | 门控融合后的语义表示 |
| $z_i^{str}$ | 层选择后的结构表示 |
| $N_K(i)$ | 为实体 $i$ 选择的固定预算邻居集合 |
| $c_i^{str}$ | 语义引导后形成的结构上下文 |
| $z_i^{joint}$ | 最终用于检索和训练的联合表示 |
| $\tau$ | InfoNCE 温度，默认 0.07 |
| $\gamma$ | margin 损失中的间隔，默认 0.2 |

### 3.4 总体架构与交互机制

模型的输入包含统一编号后的两张关系图、关系类型、实体语义序列和种子对齐。结构分支先在整图上执行关系感知消息传递，得到所有实体的结构表示；语义分支只对当前批次的实体序列编码；随后从结构矩阵中提取实体自身和固定预算邻居。融合模块以语义向量为查询，对这些结构邻居进行注意力打分和语义门控，形成结构上下文，再与语义表示生成 $z^{joint}$。训练目标直接作用于联合表示，并可选择对结构、语义和联合空间施加一致性约束。

本文将“协同”严格定义为两个可定位的信息交互点：其一，语义状态在结构邻居聚合之前参与邻居可信度判断；其二，结构上下文与语义状态通过逐维门控共同形成最终联合表示。关闭跨模态增强后，模型退化为归一化的 $0.5(z^{str}+z^{sem})$，因此可以通过消融直接检验该交互是否必要。

### 3.5 数据预处理与统一索引

两张图首先映射到同一个全局节点编号空间，第二张图的节点编号整体增加 $|E_1|$。DBP15K 数据及其对齐划分源自 JAPE[2]，OpenEA 数据采用标准化实体对齐基准提供的划分[16]。DBP15K 的关系词表通过规范化 DBpedia URI 后缀和已知关系对齐文件合并为全局关系编号；OpenEA 则按规范化后的关系名称建立共享关系编号。边保留原始方向，消息沿输入的 $(source,target)$ 方向聚合。

DBP15K 的语义序列使用已有预处理特征，形状为 $(38960,14,300)$。OpenEA 的语义序列由实体标识、关系名称、属性名称和属性值的 token 组成，最大长度为 32；词表中的 token 使用 GloVe 300 维向量[17]，词表外 token 使用基于 MD5 种子的确定性随机向量。两个数据集的语义输入来源和长度不同，因而跨数据集差异不能仅归因于模型结构。

### 3.6 关系感知轻量结构编码器

本节说明结构分支如何将实体自身状态、边的关系类型以及不同传播深度的邻域信息编码到统一表示中。编码过程依次包括关系感知消息构造、入邻域聚合、门控状态更新和节点级层选择。

#### 3.6.1 关系感知消息构造

设实体 $i$ 在第 $l$ 层的结构状态为 $h_i^{(l)}$，初始状态 $h_i^{(0)}\in\mathbb{R}^{128}$ 为可学习向量。对于有向三元组 $(j,r,i)$，即实体 $j$ 通过关系 $r$ 指向实体 $i$，从 $j$ 传递至 $i$ 的消息定义为

$$m_{jri}^{(l)}=\operatorname{LayerNorm}\left(W_s^{(l)}h_j^{(l)}+W_r^{(l)}e_r\right). \tag{1}$$

其中，$e_r$ 是关系 $r$ 的可学习嵌入，$W_s^{(l)}$ 和 $W_r^{(l)}$ 分别将源实体状态与关系嵌入投影到同一消息空间。二者在同一层的所有关系类型之间共享，而不是为每种关系分别学习一个完整的变换矩阵。不同边仍可通过各自的关系嵌入 $e_r$ 产生不同消息，因此该设计在保留关系区分能力的同时减少了参数量。若关系数为 $R$、隐藏维度为 $d$，关系专属矩阵通常需要 $O(Rd^2)$ 级参数，而共享投影与关系嵌入约需要 $O(d^2+Rd)$ 级参数。这里的“共享”是指跨关系类型共享；是否在不同传播层之间共享参数由独立配置控制。

#### 3.6.2 入邻域聚合与门控更新

记 $N_{in}(i)$ 为实体 $i$ 的入邻居集合。模型对所有指向 $i$ 的消息取均值：

$$\bar m_i^{(l)}=\frac{1}{\max(1,|N_{in}(i)|)}\sum_{(j,r,i)}m_{jri}^{(l)}. \tag{2}$$

均值聚合可以避免高入度实体仅因邻居数量较多而产生过大的表示幅值。当实体没有入邻居时，求和结果为零向量，分母中的 $\max(1,\cdot)$ 用于避免除零。

随后，将实体自身状态投影为 $s_i^{(l)}=W_{self}^{(l)}h_i^{(l)}$，并联合自身状态与平均邻域消息计算逐维门控：

$$g_i^{(l)}=\sigma\left(W_g^{(l)}[s_i^{(l)};\bar m_i^{(l)}]\right), \tag{3}$$

$$h_i^{(l+1)}=s_i^{(l)}+g_i^{(l)}\odot\bar m_i^{(l)}. \tag{4}$$

其中，$[\cdot;\cdot]$ 表示向量拼接，$\sigma$ 为 Sigmoid 函数，$\odot$ 表示逐元素乘法。门控向量 $g_i^{(l)}$ 的每个维度均位于 $(0,1)$，用于控制对应维度上邻域消息的注入强度。需要强调的是，式（4）并非在自身信息与邻居信息之间进行二选一：自身投影 $s_i^{(l)}$ 以残差形式始终保留，门控仅调节新增的邻域证据。

以三元组“姚明—出生地→上海”为例，更新“上海”时，消息同时包含源实体“姚明”的状态和关系“出生地”的嵌入，因此模型能够将该连接与“工作地点”等其他关系区分开来；门控则进一步判断各特征维度应吸收多少邻域信息。

#### 3.6.3 层叠传播与多跳信息

除最后一层外，每层输出依次经过 LayerNorm、ReLU 和 dropout，以稳定特征尺度、引入非线性并缓解过拟合。当前主配置堆叠 $L=3$ 层消息传递：第一层聚合直接入邻居，第二层可间接获得二跳来源的信息，第三层进一步扩展到最多三跳的入向可达结构。因此，第 $l$ 层状态可视为实体自身及其最多 $l$ 跳结构上下文的综合表示。

这种多跳信息由逐层消息传递自然形成，模型并未显式枚举或匹配具体的关系路径模板。例如，模型不会单独构造“出生地→所属国家”这一二跳规则，也不会记录某条三跳路径的完整关系序列。因此，本文仅主张编码器能够利用多跳结构上下文，不将其表述为显式路径匹配模型。

#### 3.6.4 节点级层选择

仅采用最深层输出可能忽略实体自身和局部邻域信息，并增加过度平滑风险。为此，编码器保留投影后的输入状态及各传播层输出，记为 $u_i^{(0)},u_i^{(1)},\ldots,u_i^{(L)}$，分别对应 0 跳至最多 $L$ 跳的信息。首先计算各层状态的平均上下文

$$\bar u_i=\frac{1}{L+1}\sum_{k=0}^{L}u_i^{(k)},$$

再由两层 MLP 结合当前层状态与平均上下文，为每个传播深度计算归一化权重：

$$a_i^{(k)}=\operatorname{softmax}_k\left(MLP([u_i^{(k)};\bar u_i])\right). \tag{5}$$

最终结构表示为

$$z_i^{str}=\operatorname{Norm}\left(\operatorname{LayerNorm}\left(\sum_{k=0}^{L}a_i^{(k)}u_i^{(k)}\right)\right). \tag{6}$$

其中，评分 MLP 的输入维度为 $2d$，隐藏层维度为 $d$，中间使用 GELU 和 dropout，并为每一层输出一个标量分数。权重 $a_i^{(k)}$ 按实体分别计算，因而不同实体可以采用不同的有效感受野：局部证据充分的实体可提高 0 跳或浅层状态的权重，而需要更广结构背景的实体可更多利用深层状态。最后的 LayerNorm 和 $L_2$ 归一化用于稳定表示尺度，并使其适用于后续基于相似度的实体检索。

综上，该编码器分别回答三个问题：关系嵌入刻画“邻居通过何种关系到达”，逐维门控控制“注入多少邻域证据”，节点级层选择决定“综合利用多远的结构范围”。其轻量性主要来自跨关系类型共享投影和均值聚合，而非省略关系信息或多跳传播。

### 3.7 固定预算关系多样邻居选择

整图结构编码只计算一次，批次中的实体和邻居随后从 $z^{str}_{all}$ 索引。为每个实体选择 $K=8$ 个邻居。关系感知候选分数为

$$q(i\rightarrow j,r)=\frac{\alpha_r}{\sqrt{\operatorname{count}(r)+1}}+\frac{\alpha_d}{\sqrt{\operatorname{degree}(j)+1}}, \tag{7}$$

其中默认 $\alpha_r=1.0$、$\alpha_d=0.25$。第一项偏向较少见的关系，第二项降低高度 hub 邻居的优先级。候选先按分数排序，再按关系桶轮询选择，避免同一种关系占满全部预算。若实体没有邻居，系统以实体自身编号填充但将掩码置 0；若邻居少于 $K$，则循环填充已有邻居并保持有效掩码。该策略控制了融合阶段的计算量，同时保留一定关系多样性。

### 3.8 多尺度语义编码器

输入语义序列为 $X_i\in\mathbb{R}^{L\times300}$。非零行被视为有效 token，形成掩码 $M_i$。输入先经过线性投影、LayerNorm、正弦位置编码和 dropout，得到 $H_i\in\mathbb{R}^{L\times128}$。

token 视图同时使用掩码均值池化和注意力池化：

$$z_i^{tok}=\frac{1}{2}\left(\operatorname{MeanPool}(H_i,M_i)+\operatorname{AttnPool}(H_i,M_i)\right). \tag{8}$$

注意力池化器是两层全连接网络：$128\rightarrow128\rightarrow1$，中间使用 GELU 和 dropout，再对有效位置做 softmax。

phrase 视图使用卷积核 3 和 5 捕获局部词组模式：

$$H_i^{phr}=\operatorname{LayerNorm}\left(H_i+\frac{1}{2}(Conv_3(H_i)+Conv_5(H_i))\right), \tag{9}$$

$$z_i^{phr}=\frac{1}{2}\left(\operatorname{MeanPool}(H_i^{phr},M_i)+\operatorname{AttnPool}(H_i^{phr},M_i)\right). \tag{10}$$

global 视图采用两层、四头 Transformer Encoder，前馈层宽度为 $4d=512$，激活函数为 GELU：

$$H_i^{glo}=\operatorname{Transformer}(H_i,M_i), \tag{11}$$

$$z_i^{glo}=\frac{1}{2}\left(\operatorname{MeanPool}(H_i^{glo},M_i)+\operatorname{AttnPool}(H_i^{glo},M_i)\right). \tag{12}$$

三个视图拼接后进入 $384\rightarrow128\rightarrow3$ 的门控 MLP。禁用的视图在 softmax 前被赋予极小 logits，因此权重只在启用视图间归一化：

$$[\pi_{tok},\pi_{phr},\pi_{glo}]=\operatorname{softmax}(MLP([z_i^{tok};z_i^{phr};z_i^{glo}])). \tag{13}$$

加权后的三个向量仍以拼接形式进入 $384\rightarrow128\rightarrow128$ 输出 MLP，并加上 global 视图残差；若 global 视图关闭，则使用其余启用视图的均值作为残差。最终结果进行 $L_2$ 归一化得到 $z_i^{sem}$。选择 MLP 而不是固定加权的原因是，不同实体的短标签、属性片段和全局上下文质量不同，逐实体门控可以表达这种差异；但第 5.5 节结果也表明，当前门控并未稳定优于单独 phrase 视图，因此该设计仍需改进。

### 3.9 语义引导的结构上下文与联合表示

对于实体 $i$，输入为语义表示 $s=z_i^{sem}$、自身结构表示 $t_i=z_i^{str}$、邻居结构矩阵 $T_i=[t_{i1},\ldots,t_{iK}]$ 和有效掩码。语义查询与结构键值的基础注意力为

$$a_{ik}=\frac{(W_Kt_{ik})^T(W_Qs)}{\sqrt d}. \tag{14}$$

为显式表示两个向量的匹配关系，融合模块使用

$$\phi(x,y)=[x;y;x\odot y;|x-y|]. \tag{15}$$

其中 $x$ 和 $y$ 保留独立证据，逐元素乘积表示同维度上的共同激活，绝对差表示不一致程度。邻居语义门控为

$$p_{ik}=\sigma(W_p\phi(t_{ik},s)), \tag{16}$$

并以对数形式加到注意力分数中：

$$\alpha_{ik}=\operatorname{softmax}_k(a_{ik}+\log(p_{ik}+\epsilon)+\operatorname{mask}_{ik}). \tag{17}$$

结构邻居摘要为 $n_i=\sum_k\alpha_{ik}W_Vt_{ik}$。随后使用另一个逐维门控决定信任自身还是邻居：

$$c_i=\sigma(W_c[\phi(t_i,n_i);s]), \tag{18}$$

$$c_i^{str}=c_i\odot t_i+(1-c_i)\odot n_i. \tag{19}$$

没有有效邻居时，$c_i^{str}=t_i$。最后分别归一化 $s$ 与 $c_i^{str}$，并用联合门控

$$g_i=\sigma(W_j\phi(s,c_i^{str})), \tag{20}$$

$$z_i^{joint}=\operatorname{Norm}(g_i\odot c_i^{str}+(1-g_i)\odot s). \tag{21}$$

本文仅将公式（14）—（21）所定义的前向计算视为早期交互机制；实验不包含未进入该计算路径的预留投影或残差参数，因而不对双向残差增强作额外机制主张。

为回答“为什么不在两个分支完成后直接拼接”，本文另外设置两个不使用结构邻居的控制组。晚期拼接基线先独立得到并归一化 $t_i$ 和 $s_i$，再计算

$$z_i^{late}=\operatorname{Norm}\left(W_2\operatorname{Dropout}\left(\operatorname{GELU}\left(W_1[\operatorname{Norm}(t_i);\operatorname{Norm}(s_i)]\right)\right)\right). \tag{22}$$

其中，$W_1\in\mathbb{R}^{128\times256}$，$W_2\in\mathbb{R}^{128\times128}$。

另一个无参数平均基线为 $z_i^{mean}=\operatorname{Norm}((\operatorname{Norm}(t_i)+\operatorname{Norm}(s_i))/2)$。两种控制组均保留相同的结构与语义编码器，仅改变交互发生的位置和形式。

按实际前向路径统计，早期交互模块包含 197,377 个可训练参数，晚期拼接 MLP 包含 49,408 个，简单平均不增加融合参数。因此，融合对照同时改变了交互位置、邻居信息可见范围和模块容量；该设计可以检验末端融合是否足够，但不能把全部性能差异唯一归因于交互时机。

### 3.10 对齐目标与两阶段训练

阶段一为结构预热。左右图结构表示分别计算维度标准差，并惩罚低于 1 的部分：

$$L_{warm}=\frac{1}{2}\sum_{q\in\{L,R\}}\operatorname{mean}\left(\max(0,1-\operatorname{Std}(z_q^{str}))\right). \tag{23}$$

该目标意图在联合训练前降低表示塌缩风险，但由于 $z^{str}$ 已做单位归一化，其每维标准差通常远小于 1。日志中预热损失长期约为 0.911，且无预热单次实验略优于基线，因此目前只能称为“已实现的稳定化尝试”，不能声称其必要性已经得到证明。

阶段二以联合表示上的双向 InfoNCE 为主目标。对于批次中 $B$ 个已对齐实体对，

$$S_{ij}=\frac{\cos(z_{Li}^{joint},z_{Rj}^{joint})}{\tau}, \tag{24}$$

$$L_{align}=\frac{1}{2}\left(CE(S,[0,\ldots,B-1])+CE(S^T,[0,\ldots,B-1])\right). \tag{25}$$

采样负样本间隔损失要求真实对分数至少比难负样本高 $\gamma$：

$$L_{neg}=\frac{1}{B}\sum_i\max(0,\gamma-s_i^++s_i^-). \tag{26}$$

排序损失同时搜索批内左右方向的最强错误候选，并可合并采样负例：

$$L_{rank}=\frac{1}{B}\sum_i\max(0,\gamma-s_i^++\max(s_{i,batch}^-,s_{i,sampled}^-)). \tag{27}$$

完整训练框架还支持结构分支对齐、语义分支对齐、跨模态一致性、联合—分支一致性，以及主动学习负反馈损失。这些辅助项在联合训练进程中按线性 ramp-up 逐渐增大：

$$\omega(p;s,e)=\begin{cases}0,&p\le s\\(p-s)/(e-s),&s<p<e\\1,&p\ge e\end{cases}. \tag{28}$$

完整目标可写为

$$\begin{aligned}L=&L_{align}+\lambda_b\omega_bL_{branch}+\lambda_c\omega_cL_{cross}+\lambda_j\omega_jL_{joint-branch}\\&+\lambda_sL_{str}+\lambda_mL_{sem}+\lambda_nL_{neg}+\lambda_n\lambda_{al}L_{al-neg}+\lambda_rL_{rank}.\end{aligned} \tag{29}$$

本文区分完整目标与主实验协议。两数据集的三随机种子实验令 $\lambda_b=\lambda_c=\lambda_j=\lambda_s=\lambda_m=0$，保留 $L_{align}$、$L_{neg}$ 和 $L_{rank}$，从而将主要证据集中于表示架构与难负样本边界。优化器采用 AdamW[18]；DBP15K 的学习率为 $5\times10^{-4}$，包含 3 个预热 epoch 和 36 个联合训练 epoch；OpenEA 的学习率为 $3\times10^{-4}$，包含 5 个预热 epoch 和 50 个联合训练 epoch。DBP15K 对最后 10 个 epoch 的权重做平均，OpenEA 根据验证集 MRR 选择检查点。

### 3.11 检索、CSLS 与可选重排序器

主排序指标使用联合表示的原始余弦相似度，并以 CSLS 校正作为补充评价[19]：

$$\operatorname{CSLS}(x,y)=2\cos(x,y)-r_x-r_y, \tag{30}$$

其中 $r_x$ 和 $r_y$ 分别是实体到另一侧最近 $k=10$ 个候选的平均相似度。CSLS 用于减轻少数 hub 实体在高维空间中成为过多实体最近邻的问题。本文将原始余弦结果作为主结果，将 CSLS 结果标为补充指标，不混合报告。

系统还支持一个可选 MLP 重排序器。它对基础检索的 top-$K$ 候选构造联合、结构和语义配对特征，再输出新的候选分数。重排序器不属于主模型的必要路径，在三随机种子实验中作为可选扩展单独报告。

### 3.12 主动学习闭环

主动学习协议先从完整训练对齐中保留一定比例作为初始种子，其余对齐进入候选池。每隔固定 epoch，模型对左侧候选实体执行分块全排名，获得第一、第二候选和分差。ActiveEA 风格的基础不确定性由负 margin 归一化得到，并在左侧图邻域传播：

$$u^{(t+1)}=\alpha Pu^{(t)}+(1-\alpha)u^{(0)}, \tag{31}$$

其中 $P$ 表示候选实体之间的邻接传播，默认 $\alpha=0.5$。系统同时提供基于熵、置信度、互惠匹配和多视图代表性的混合查询策略。候选可经过双向一致性、最小置信度、最小 margin 和不确定性区间过滤；当过滤后数量不足时，系统按预设阶段逐步放宽条件，而不是静默返回过少样本。

oracle 模式利用候选池真值模拟人工标注者的反馈。entity 查询单元为被选左实体返回真实右侧对应，并把展示的其他 top-$K$ 候选记为负例。human 模式则导出 CSV，包含实体 URI、可读表面形式、候选分数、双向置信度和 margin；训练保存会话后暂停，待标注者填写 match、no_match 或 skip，再从同一状态恢复。正例加入训练集，负例进入显式负监督集合。该实现避免了把模型预测直接当作伪标签，但当前实验仍主要使用 oracle 模式。

| w/o 多尺度语义编码器（MST） | 0.6699±0.0025 | 0.7189±0.0011 | 0.3138±0.0125 | 0.4078±0.0106 |
| 仅 InfoNCE | 0.6762±0.0021 | 0.7230±0.0011 | 0.4877±0.0101 | 0.5606±0.0095 |
| 无 hard negative | 0.6761±0.0010 | 0.7230±0.0007 | 0.4863±0.0143 | 0.5584±0.0133 |
| 无 ranking loss | 0.6766±0.0012 | 0.7233±0.0008 | 0.4886±0.0127 | 0.5602±0.0119 |

跨模态增强是当前最稳定的必要组件：关闭它后，DBP15K Hits@1 下降 0.0562，OpenEA 下降 0.0668。由于关闭时结构与语义仍以简单平均得到联合表示，这一差异支持“在聚合前让语义选择结构上下文”优于末端平均融合；第 5.4 节进一步加入带参数的晚期拼接 MLP，以检验结论是否仅来自简单平均基线过弱。

多尺度语义编码器在 DBP15K 上带来较小提升，但在 OpenEA 上非常关键，Hits@1 相差 0.1747。这与 OpenEA 使用更长的属性语义序列一致：简单文本编码器难以同时处理关系名、属性名和值组成的 32 个 token。相反，难负样本和排序损失在当前三种子实验中的收益很小；`only_infonce` 在 OpenEA MRR 上甚至略高于主模型。这意味着当前 margin、负样本数量和采样策略仍需调优，不能把复合损失本身描述为已证实创新。

### 5.4 早期交互、晚期拼接与简单平均

为直接回答“为什么不在最后拼接”的实验问题，本组实验保留相同的数据划分、结构编码器、语义编码器、损失函数、训练轮数、随机种子和检索流程，仅替换第 3.9 节的融合路径。早期交互在形成结构上下文前用语义状态选择和过滤邻居；晚期拼接 MLP 让两个分支独立完成编码，再对归一化表示进行两层投影；简单平均不增加融合参数。三种设置均运行随机种子 42、43、44，表中报告均值与样本标准差。

| 融合方式 | DBP H@1 | DBP H@10 | DBP MRR | OpenEA H@1 | OpenEA H@10 | OpenEA MRR |
|---|---:|---:|---:|---:|---:|---:|
| 早期语义引导交互 | 0.6768±0.0005 | 0.8061±0.0006 | 0.7234±0.0004 | 0.4885±0.0112 | 0.6952±0.0113 | 0.5601±0.0106 |
| 晚期拼接 + MLP | 0.5782±0.0024 | 0.7311±0.0033 | 0.6327±0.0023 | 0.2153±0.0368 | 0.4615±0.0382 | 0.2991±0.0372 |
| 末端简单平均 | 0.6206±0.0013 | 0.7703±0.0008 | 0.6740±0.0011 | 0.4216±0.0117 | 0.6394±0.0090 | 0.4972±0.0101 |

早期交互相对晚期拼接在 DBP15K 和 OpenEA 上分别提高 Hits@1 0.0987 和 0.2731，三个随机种子方向一致。晚期拼接还分别低于简单平均 0.0425 和 0.2063，说明增加一个末端 MLP 并不会自动带来更好的联合空间；一个可能原因是该 MLP 在没有显式分支对齐约束时重新混合两个已成形空间，反而破坏了可直接比较的方向信息。该解释仍需表征相似性或门控可视化进一步验证，本文不把它写成已经证实的机制。OpenEA 晚期拼接 Hits@1 的样本标准差为 0.0368，明显高于早期交互的 0.0112，说明该路径不仅均值较低，而且对初始化更敏感。

该对照支持“早期语义条件化结构聚合优于本文设置的两个晚期融合基线”，但不能把全部差值唯一归因于交互时机。早期模块实际前向使用 197,377 个融合参数，并访问固定预算结构邻居；晚期 MLP 使用 49,408 个参数且不访问邻居；简单平均没有融合参数。因此早期交互同时改变了信息可见范围、函数形式和容量。后续应加入参数匹配的晚期 MLP、无语义邻居注意力和随机邻居注意力基线，以进一步分离这些因素。

### 5.5 补充消融分析

更细的组件实验目前只完成随机种子 42，因此下表作为探索性消融，不用于给出稳健排名或显著性结论。

| 诊断变体 | DBP H@1 | OpenEA H@1 | 相对各组 base 的观察 |
|---|---:|---:|---|
| 结构组 base | 0.6775 | 0.4861 | 参考 |
| w/o relation GNN | 0.6249 | 0.4593 | 两侧均下降，DBP 更明显 |
| w/o layer fusion | 0.6634 | 0.4542 | 跨层选择有效 |
| w/o relation-aware sampling | 0.6750 | 0.4950 | DBP 略降，OpenEA 反而提高 |
| 语义组 base | 0.6771 | 0.4866 | 参考 |
| only phrase view | 0.6851 | 0.5157 | 两侧均高于三视图 base |
| w/o global view | 0.6850 | 0.5210 | 当前 global 视图可能引入冗余 |
| only token view | 0.6812 | 0.4019 | DBP 尚可，OpenEA 明显不足 |
| no warmup | 0.6797 | 0.4886 | 均略高于对应 core base |

关系感知消息和层融合的下降方向一致，说明它们是结构分支中较可信的组成部分。关系感知邻居采样则没有跨数据集一致收益：OpenEA 关闭后反而提高 0.0089，可能是关系稀有度启发式偏向噪声或低频关系。

语义视图结果对最初假设提出了更强挑战。单独 phrase 视图或关闭 global 视图在两个数据集上都超过三视图 base，说明当前 Transformer global 分支和三路门控没有实现稳定互补。一个合理解释是输入序列较短，卷积已经覆盖主要局部语义，而全局注意力在样本量有限时增加了参数和噪声。后续应做三随机种子复验，并检查门控权重分布、视图相关性和 global 分支的过拟合，而不是继续增加更多语义层。

### 5.6 主动学习结果

主动学习使用 20% 初始种子、5 轮查询、每轮预算 90，当前结果为随机种子 42。`same_budget_no_query` 直接使用与“初始种子 + 450 次查询”相同数量的随机已知标签，但不执行主动查询；`full_train_no_al` 使用完整训练集，因此仅表示上限式基线。

| 数据集 | 设置 | Hits@1 | Hits@10 | MRR |
|---|---|---:|---:|---:|
| DBP15K | 20% seed，无查询 | 0.6129 | 0.7461 | 0.6605 |
| DBP15K | ActiveEA-style 5×90 | 0.6204 | 0.7566 | 0.6702 |
| DBP15K | 同预算，无查询 | 0.6351 | 0.7625 | 0.6809 |
| DBP15K | 完整训练集，无 AL | 0.6776 | 0.8056 | 0.7239 |
| OpenEA | 20% seed，无查询 | 0.1254 | 0.3346 | 0.1963 |
| OpenEA | ActiveEA-style 5×90 | 0.2312 | 0.4692 | 0.3127 |
| OpenEA | 同预算，无查询 | 0.2125 | 0.4547 | 0.2953 |
| OpenEA | 完整训练集，无 AL | 0.4858 | 0.6972 | 0.5576 |

主动查询相对于 20% seed 基线在两个数据集上都有提升，OpenEA 的提升更明显；与同预算无查询相比，OpenEA Hits@1 提高 0.0187，而 DBP15K 下降 0.0147。因此，当前主动学习尚不能得到“普遍提高样本效率”的结论。更严格的评价需要至少三随机种子、相同标注数量、相同训练 epoch，并把人工查询的负例数量也纳入预算。完整训练集基线使用更多标签，不能用于证明主动学习失败或成功，只能说明当前低预算方案与完整监督之间仍有较大差距。

## 6 讨论

### 6.1 主要发现

三随机种子结果最清楚地支持两点。首先，语义引导的结构上下文形成同时优于晚期拼接 MLP 和简单平均，且两个数据集、三个随机种子的方向一致；这比只和无参数平均比较更直接地回答了交互位置问题。其次，能够处理局部词组和上下文的语义编码器对较长、由属性拼接而成的 OpenEA 输入非常重要。单随机种子结构实验进一步支持关系感知消息和节点级层融合，但仍需多随机种子确认效应大小。

### 6.2 结果解释与未获支持的假设

三视图一定优于单视图的结论不成立，global 视图在当前单次实验中反而降低结果。两阶段预热一定改善性能的结论也不成立，无预热变体略高于 base。难负样本和 ranking loss 的增益接近随机波动。主动学习虽然比极少种子基线更好，但没有在两个数据集上都超过同预算方案，更未超过完整训练集基线。将这些负面结果写入论文能够明确下一步优化方向，并避免把系统设计目标误写成已经验证的事实。

### 6.3 研究局限

内部有效性方面，细粒度语义和结构实验目前多为单随机种子；不同实验组的基线结果存在约 $10^{-4}$ 到 $10^{-3}$ 的波动。融合对照虽然使用三随机种子，但早期、晚期和平均路径的参数容量与邻居可见范围不同，只能证明完整模型优于这两个控制组，不能得到纯粹的交互时机因果效应。外部有效性方面，本文只覆盖 DBP15K ZH–EN 和 OpenEA EN–FR 15K V2，尚未验证更大规模、开放世界或无对应实体场景。构念有效性方面，Hits@1、Hits@10 和 MRR 衡量排名，却不直接衡量人工标注时间、模型解释质量或部署成本。比较有效性方面，文献方法的文本输入、翻译工具、随机划分和评估后处理不同，不能仅凭一张表得出严格优劣结论。

### 6.4 研究启示与后续工作

后续研究应优先解决四个问题。第一，补充参数匹配的晚期融合与不使用语义查询的邻居聚合基线，以分离交互时机、邻居信息和模型容量。第二，对 token、phrase、global 视图开展三随机种子组合实验，并分析门控权重和视图相似度，以判断 global 分支的性能下降来自过拟合还是信息重复。第三，重新设计预热方差目标，使其尺度与单位归一化表示一致，并通过无预热对照验证。第四，在主动学习中加入无对应实体识别、真实人工标注成本和三随机种子同预算比较，同时避免验证集或测试真值进入查询流程。

## 7 结论

本文构建了一套结合关系感知结构建模、多尺度语义编码和语义引导结构上下文融合的知识图谱实体对齐方法。模型通过关系嵌入消息、节点级层选择、三尺度语义表示和两级门控，将结构与语义交互置于最终检索之前。两数据集三随机种子实验表明，早期语义引导交互稳定优于本文设置的晚期拼接 MLP 与简单平均，多尺度语义编码器在 OpenEA 上具有较大贡献；关系感知消息与层融合也得到探索性消融支持。与此同时，global 语义视图、结构预热、复合负样本目标和主动学习尚未获得一致优势。

因此，本文不主张所有组件均有效或已经达到最优性能。现有证据支持关系感知结构编码和语义引导早期交互，同时表明语义视图组合与低预算主动学习仍需更严格的实验验证。该结论界定了方法的有效范围，也为后续参数匹配对照和跨数据集复验提供了明确基础。
